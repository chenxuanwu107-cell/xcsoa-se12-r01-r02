# 个人使用：按兼容配置操作，不逐次做法律判断

**v0.1.0 许可已于 2026-11-03 采用 / LEGAL_REVIEW_REQUIRED。**
按根 LICENSE，在指定 rc.2 获准公开时向将来生效。G1 已公开 rc.1，旧版历史许可声明
不改；许可人已提供本人授权声明，没有独立权属裁决或已审核云端配置。

## 对许可已适用的发行，个人只需三步

1. **选择发行方已审核的配置。** 发行说明应给出“产品／功能＋条款版本＋适用账号类型＋
   必要设置”的兼容配置，明确可用、待核或不适用。没有已审核配置时，向维护者提供
   产品与功能名称即可请求核查，不需要每位用户自己给条款作法律结论。
2. **确认仍由自己独立控制。** 客户只提需求和接收普通成果；不能拥有工作区管理权、
   Skill 部署、密钥、Skill API 或代理调用能力。不要自行开启未包含在配置内的
   共享 GPT、插件上架、客户工作区或额外数据共享。
3. **按该配置使用并交付普通成果。** 不交付 Skill 本体或其受保护内容的实质性复制。
   同一配置无需每次重新审查；产品功能、账号控制、必要设置或适用条款实际变化时，
   才检查维护者更新。普通客户需求变化不自动触发新一轮法律研究。

个人账号、关闭训练、本地 Codex 客户端都不是兼容证明。“个人向模型 API 发请求”
与“企业客户取得 Skill API”是两个不同安排，不能一概允许或禁止。

## 已有证据与尚未审核的配置

| 路径 | 当前结论 | 个人应做什么 |
|---|---|---|
| 既往隔离、本地 MLX 测试 | 已观察到有限安装与 Smoke 结果；不代替根 LICENSE 的适用与生效条件 | 审阅工程报告，不能据此认为 Codex 原生发现或生产资格通过 |
| Codex／ChatGPT 个人云端账号 | 尚无已批准的本项目云端兼容配置 | 等发行方完成具体配置核查；不是要求每次使用都自行找律师 |
| 个人独立控制的 API 开发账号 | 必要技术处理条款已采用；实际签约资格、协议及控制未核 | 提供产品／功能类型给维护者，不发送密钥或私人合同到公开渠道 |
| 客户管理的工作区、客户 Skill API、代理运行 | 不符合本项目保留的独立使用边界 | 不以私人账号或承包商安排规避 |
| 合法持有的完全本地模型 | 无云端协议的额外处理授权问题；模型自身权利、硬件和实际安装仍需满足 | 不能把本轮加载器测试当成所有宿主通用安装证明 |

## 由发行方维护的一张配置卡

每个可推荐配置只记录：产品／功能、账号与控制边界、已核条款及日期、必要处理权利、
必要设置、审核状态与已知限制、重新核查的实际触发条件。审核前标为“待核”，不靠
软件名称或无训练设置自动转为“可用”。这是发布维护责任，不是新增运行审批服务。

本次采用没有批准具体云端配置，也未查看或改变真实账号。已有
[云端边界分析](../legal/CLOUD_PROCESSING.md)继续作为维护者依据，
不要求普通个人每次阅读整份法律研究。实际安装结果见
[历史工程报告](../reports/PREPUBLICATION_2.md)。
